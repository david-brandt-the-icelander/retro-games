# Inkwell Academy

An original school-day caper, made in Godot 4 for the web and served at
<https://icelander.net/games/retro/inkwell-academy/> to anyone signed in to icelander.net.

You are Pip, a pupil at a three-storey school. Follow the timetable: get to each lesson's room and sit
down before the teacher starts checking, or collect lines. Teachers only see what is in front of them.
Only a desk is a seat, and only one kid sits at each: punch a sitting kid and they hit the floor, so you can
take the seat; but if a kid takes *your* desk you are shoved to the floor, and a teacher who spots you
punching or sitting on the floor gives you lines (with a furious scream). Light all eight school crests with your pea-shooter, then pull the Founder's Bell rope in the Head's
study for a half-holiday (+5,000 points and 3,000 lines forgiven). Knuckles knocks you flat between
lessons, and Tattle tells a teacher if he sees you fire. 10,000 lines and you're expelled.

| Action | Keys |
|---|---|
| Walk | ←/→ or A/D |
| Stairs | ↑/↓ (or W) at the foot or head of a staircase |
| Sit / stand (at a desk only) | S |
| Punch | X or Z |
| Pea-shooter | F or Space |
| Bell rope | E |
| Pause / sound | P or Esc / M |

## Provenance

The school-timetable caper is a well-known genre. Everything in this folder was made from scratch for
this game: the name, the school, the cast and their names, the dialogue, the rules' numbers and the code.
The artwork is SVG generated by `tools/make_art.py` (cut-out characters, rooms, props) and the sound
effects are synthesised by `tools/make_audio.py`. The fonts are Fredoka and Caveat, under the SIL Open
Font License (`godot/fonts/OFL-*.txt`).

## Code

- `godot/`: the Godot 4.7 project (Compatibility renderer, for the web). `scripts/main.gd` builds the
  world and HUD and runs the timetable, the teachers' and pupils' behaviour and the rules;
  `scripts/chara.gd` is the cut-out character rig with its walk, sit and knocked-down animations.
  `art/`, `audio/` and `fonts/` are its assets; `web_shell/shell.html` is the page the export is built into.
- `tools/`: `make_art.py` and `make_audio.py` regenerate `godot/art/` and `godot/audio/` (Python 3 with numpy).
  Change a colour or a shape there and run them again to restyle the game.
- `web/`: the page's loader script (`boot.js`), styles, icon and `_headers` (a strict Content-Security-Policy).
- `worker/index.ts`: the Worker. It asks for icelander.net's sign-in (role `games:play`) before serving the
  page, joins the engine's parts back into `index.wasm`, and serves everything else as static assets.
- `test/`: the Worker's tests (`npm test`). `npm run test:godot` runs the game headless with `--selftest`,
  which checks the stairs, crests, lines, knocking a teacher down, the Founder's Bell, a whole day of the
  timetable and being expelled, and fails on any script error.

The best score is kept in the browser (`user://inkwell.cfg`); there is no server-side table.

## Build and deploy

Needs Godot 4.7.2 with its web export templates on the PATH as `godot` (or set `GODOT`).

```bash
npm install
npm test && npm run test:godot
npm run build      # dist/games/retro/inkwell-academy/, with the engine split under Cloudflare's 25 MiB limit
```

A merge to `main` deploys it (`.github/workflows/deploy.yml`); `npm run deploy` does the same by hand.
It has no database and no secrets.
