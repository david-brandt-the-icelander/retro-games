# Kvarðinn: spjöldin (kvarðarnir)
#
# Ein lína er eitt spjald: vinstri endi, örin ↔ og hægri endi. Í stað ↔ má líka skrifa <-> eða |
# Línur sem byrja á # eru athugasemdir og tómar línur skipta engu.
# Eftir breytingu: npm test (athugar skrána) og síðan dreifing (README.md).
