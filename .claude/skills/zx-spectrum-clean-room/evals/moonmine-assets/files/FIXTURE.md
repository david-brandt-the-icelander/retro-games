Fixture for the zx-spectrum-clean-room test case. "Moonmine" (1984,
"Quillsoft", by "R. N. Quill") is an invented game: original/MOONMINE.TAP is a
Spectrum tape image written for this test. It holds a BASIC program with UDG
graphics and BEEP tunes, plus a CODE block holding the game's messages.
moonmine-remake/ is a deliberately over-faithful clone. Its src/font.js claims
to be a ROM dump but contains invented bytes, not the real Sinclair ROM font.
